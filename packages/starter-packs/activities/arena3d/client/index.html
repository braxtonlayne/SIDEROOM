    Make your own game from this

    Arena 3D is SIDE ROOM's 3D starter kit. Everything here is meant to be copied. The full guide is the “Make your own game from this starter” section of README.md in the packages/starter-packs/activities/arena3d folder of SIDE ROOM's source.

    1. Copy the folder to packages/starter-packs/activities/<your-game>, rename the package and change id, name and description in sideroom.json.
    2. Change the level in sim/level.js: blocks, boxes, spawn points, the goal.
    3. Change the rules in sim/world.js (TUNING, movePlayer, afterStep). Keep it deterministic: integer inputs, the seeded PRNG, no clocks.
    4. Add to the snapshot anything new the host must send (World.snapshot, net/codec.js), and bump PROTOCOL_VERSION.
    5. Draw it in client/scene.js; load models through assets/.
    6. Prove it: pnpm test runs the determinism gate, then pnpm build checks the bundle against SIDE ROOM's rules.
