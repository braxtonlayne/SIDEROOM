**The Jolt file and the bundle rules.** `jolt-physics.wasm-compat.js` (1.1.1) has no `eval`, no `new Function`,
no `fetch` and no worker; its WASM is an embedded string. It does break two rules: its header comment contains
`https://github.com/jrouwe/JoltPhysics.js`, and Emscripten's Node start-up has `await import("node:module")`
(only reached when `process.versions.node` is set). The checks were **not** weakened. `tools/bundle.mjs`
applies two exact, counted string rewrites (`JOLT_REWRITES`: drop the URL scheme; replace the Node-only import
with an object whose `createRequire` throws) and pins the input file's sha256 (`JOLT_SHA256`), so a version bump
stops the build until someone re-checks. A test runs the rewritten file on its browser start-up path
(`process.type = 'renderer'`) and gets the same replay hash as the npm package.

## 2. Not done

- **Browser replay hashes.** I could not run real browsers here, so I did not collect the hashes of
  `replay/replay.html` in Chromium, Firefox or WebKit. The Node hash to compare with is below. The closest proxy I
  could run: the bundled, rewritten Jolt file on its non-Node start-up path gives the same hash as the npm build.
- **The demo was never run in a browser.** WebGPU/WebGL2 drawing, pointer lock, the menu and sound are checked by
  recording fakes, the type checker and a read-through only. Someone should open `dist/index.html` in two tabs
  (and through SIDE ROOM) before release.
- **An independent read-through of the browser-only code** (a second agent, no browser) found seven issues; all
  are fixed: Ctrl no longer crouches (Ctrl+W would close the tab); a refused pointer lock is caught through
  `pointerlockerror` (Firefox/Safari); textures upload as sRGB (`rgba8unorm-srgb` / `SRGB8_ALPHA8`) so they are not
  gamma-encoded twice; the host session starts at boot (peers are answered before the host presses Play) and
  ticks from a timer while its tab is hidden; WebGPU shader/pipeline errors are caught in an error scope before the
  canvas is claimed, so WebGL2 can still take over; Jolt loads in a background tab; the dev-tab election
  tie-breaks and re-elects. Still open: browsers throttle hidden-tab timers (often to 1 Hz), so a host whose tab is
  hidden lags its peers, and there is no `webglcontextlost` / WebGPU device-lost recovery beyond a "reload" message.
- **Touch controls.** Brief §4 does not ask for them and the demo has none, so a guest on a phone can watch but
  not play.
- **Render interpolation of the local player** between ticks (it is drawn at its latest predicted tick).
- **Textured materials in the render path are wired but only exercised by the sample model**, and only through
  fakes.

## 5. Owner questions (decided with a default)

1. **`connect: ["self"]` in arena3d's manifest.** The sandbox CSP is `connect-src 'none'` unless the manifest
   names hosts, so `fetch` of the bundle's own `assets/models/*.json` needs it. Default: declared. Alternative:
   ship models as JS modules (covered by `script-src 'self'`) and drop `connect`.
2. **Rewriting two strings in the vendored Jolt file** (header URL scheme, Node-only `import("node:module")`),
   pinned by sha256 and counted. Default: done, documented in `tools/bundle.mjs` and `NOTICE.md`.
3. **"Commented example" for reserved capabilities.** JSON cannot hold comments. Default: a `_comment` key and a
   `_reserved_capabilities_example` key (the server ignores unknown keys; `crates/sr-activities` `parse_manifest`
   reads only known ones).
4. **Character vs character.** Players collide through Jolt's inner kinematic body per character (simple and
   deterministic) rather than `CharacterVsCharacterCollisionSimple`. Default: inner bodies.
5. **Snapshot channel.** Snapshots go through `sdk.state` (`host:snap`, base64) so a newcomer gets the latest at
   once. Default: `state` at 20 Hz (~1 KiB each), welcome and full messages through `input.reply`.
6. **Max players 8** (`max_participants: 8`, one per spawn point and slot colour). Default: 8.
7. **Peers start from any seed.** The first snapshot overwrites every body, so the peer's world seed does not
   matter. The host seeds from the instance id.
8. **Host-side name.** Members are named from `getInstanceConnectedParticipants` (members only), unless they set
   a name in Settings; guests use the relay's `callsign`.
