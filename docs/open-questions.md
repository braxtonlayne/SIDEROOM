## Social model (`feat/LNG-social-model`)

102. **Ignore is a relationship type, so it replaces a friendship.** Docs/04 lists `ignored` beside `friend` in one `relationships.type` column (one row per pair direction), so ignoring a friend removes the friendship (both rows). The spec puts "Ignore" in the friend menu; should ignore instead be an independent flag that keeps the friendship? Ignored is stored as type 6 (Discord has no equivalent). — [relationships.rs](../crates/sr-chat/src/social/relationships.rs)

104. **Message Requests are not persisted.** `dm_access` returns Allowed/Request/Denied (non-friends need a shared server, then the recipient's `message_requests` toggle decides) but a Request DM is created like any other and is not flagged for the recipient's inbox; accept/ignore/spam folder (LNG-DM-003) need a per-recipient state column. Non-friends without a shared server cannot DM at all (Discord parity assumed). — [dm.rs](../crates/sr-chat/src/social/dm.rs)
105. **Group DM rules assumed:** 10 members including the owner, a creator needs at least two other recipients, only friends of the actor can be added (any member may add, not just the owner), adding to a 1:1 DM spawns a new group and keeps the DM, a leaving owner hands ownership to the longest-standing member, an empty group is deleted. Group DM count cap of 100 per user is invented. — [dm.rs](../crates/sr-chat/src/social/dm.rs)
