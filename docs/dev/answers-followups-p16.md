## Backend

### Live TV (D-266, D-267, D-269)

- [ ] **L-10 (P16-BE-1, D-266) The player plays the slate off air.** `crates/sr-tv/src/service.rs`: `Tune` gains `slate: bool` (true when `master_url` is the slate master; `state` stays `off_air`, `current` and `offset_ms` stay `null`); `crates/sr-api` TV routes and the OpenAPI document (`TvTune` schema, one field with a description that names D-266) and the `openapi.yml` check. Web `apps/web/src/cinema/tv/api.ts`: `OffAirError` only when there is no `master_url`; `LiveWatch.tsx` plays `master_url` when present and, while `slate` is true, draws the existing now-panel strings (`cinema.nowPanel.offAir`, `offAirNext`) over the picture instead of the failure card; the "Off the air" state of `LiveView` and the agenda are unchanged. Tests: `sr-tv/service_tests` (off air with slate: `slate: true`, `master_url` set, `current: null`; without slate: `slate: false`, no `master_url`), `sr-api/routes/tv/tests.rs` field present, web `live.test.tsx` (slate plays with the overlay, no-slate shows the card). Size: S.
- [ ] **L-11 (P16-BE-1, D-266) Slate tone at -20 dBFS.** `crates/sr-transcoder/src/slate.rs`: the sine source is followed by `-af volume=-20dB` so the tone sits around -20 dBFS; the args tests assert the filter. Size: XS.
- [ ] **L-12 (P16-BE-2, D-267) One media-sequence domain: the slate chains with the programmes.** `crates/sr-tv/src/live.rs` and `service.rs`: remove `SLATE_SEQ_BASE`; `render_slate_media` takes the chaining origin (the stored `seq_base`/`disc_base` and the on-air count of the last block with media that ended before `now`, found through `blocks_overlapping`), numbers the first slate segment after that end as last + 1 with discontinuity sequence + 1, and falls back to the wall-clock seed only when the channel has no such block; `assign_bases` chains a block with no contiguous predecessor from the slate segment on air at its start (slate number + 1, discontinuity + 1) when a slate is configured, else the seed as today. The window across a slate-programme boundary in either direction lists both sides with `#EXT-X-DISCONTINUITY`, `#EXT-X-MAP` and `#EXT-X-PROGRAM-DATE-TIME` (the same rule `render_live_media` uses for a contiguous predecessor block); a loop wrap inside the slate stays as built. `live_master` off air offers the standard rung set (the slate is encoded in the standard ladder; if the configured slate lacks a rung, log once and offer the intersection). Module docs of `live.rs` ("Numbering") rewritten. Tests: `live::tests` (programme to slate: numbers continue, one discontinuity, both sides in the window; slate to programme: the same; no slate configured: seed as before), `tests/hls_sync.rs` property test over random schedules (programme, gap, programme, a slate loop of another length, a programme starting mid-slate-segment): media sequence and discontinuity sequence never decrease between two reloads and the window always contains the segment on air. Size: M.
- [ ] **L-14 (P16-BE-4, D-269) `sr-cli tv slate` and the `tv.slate_asset` setting.** `crates/sr-cli/src/main.rs`: `tv slate [--picture bars|moving] [--seconds 12]` (default bars, 12 s, 1920x1080 at 30 fps) runs `sr_transcoder::slate::slate_source_args` with the configured ffmpeg, ingests the MP4 through the ordinary transcode job (standard ladder, standard segment length) as a system-owned asset outside the Cinema catalogue (no title, no guide entry; the Admin asset list hides it and refuses to delete it while it is the slate), waits for the job, writes the asset id to the platform setting `tv.slate_asset` through the feature registry (`crates/sr-admin/src/settings.rs`, `TV_SLATE_ASSET`), prints it, and on a second run replaces the asset and deletes the previous one; refuses with a clear message when ffmpeg is not on PATH or storage is `memory:`. `crates/sr-server/src/app.rs`: `TvService::with_slate` reads `tv.slate_asset` first and `SR_TV_SLATE_ASSET` as the bootstrap fallback, and picks up a change to the setting without a restart (the same watch the other registry settings use). `sr-cli seed`: makes the slate when ffmpeg is on PATH, skips with a message otherwise. Web `apps/web/src/admin/cinema/tv/LiveTvSection.tsx`: a read-only "Off-air slate" row (configured with the asset id and length, or not, with the command to run). Doc 12 operations: one paragraph on making the slate; `getting-started.md` note. Tests: `sr-cli` unit (argument building, refusal without ffmpeg), `sr-server` Postgres (setting read before env, env fallback), web admin test for the row; no test runs ffmpeg. Size: M.
