Same conventions as [answers-followups-p13.md](answers-followups-p13.md): each item says what to change, where, and a size (XS = an hour or two, S = under half a day, M = one to two days, L = more). Pick items by number; put the question or decision id in the branch name or PR title (for example `feat/D-243-incident-actions`). Tick an item here when it merges. Migrations for this round are `0960` to `0965`, assigned per item below (`0966` to `0969` stay free); never renumber a merged file. Where an item builds on a Phase 14 branch that has not merged yet, the branch is named; land on top of it or after it. Items that only touch docs or inventory are grouped at the end.

Nothing in this round is blocked on the owner. The MLS work (VOX-E2E-001, 003, 004, 007) waits on the `openmls` download, which is asked of the owner separately and is not a J item.
