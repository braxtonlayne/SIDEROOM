Same conventions as [answers-followups.md](answers-followups.md): each item says what to change, where, and a size (S = under half a day, M = one to two days, L = more). Pick items by number; put the question or decision id in the branch name or PR title (for example `feat/D-199-gateway-age-gate`). Tick an item here when it merges. Migrations: the next free decade is assigned per item below; never renumber a merged file. Items that only touch docs or inventory are grouped at the end.

Items marked **NEEDS-OWNER** are blocked on the owner's answer; the default in the answers file applies until then and the item describes that default.
