**The Jolt file and the bundle rules.** The stock `jolt-physics.wasm-compat.js` (1.1.1) has no `eval`, `new Function`, `fetch` or worker, and its WASM is embedded. It breaks two rules: its header comment holds a GitHub URL, and Emscripten's Node-only start-up calls `await import("node:module")`. The checks were not weakened. `tools/bundle.mjs` applies two exact, counted string rewrites (`JOLT_REWRITES`). It pins the input file's sha256 (`JOLT_SHA256`), so a Jolt version bump stops the build until someone re-checks the rewrites. A test runs the rewritten file on its browser start-up path and gets the same replay hash as the npm package.

## 5. Owner questions (decided with a default)

**arena3d**
1. **`connect: ["self"]`.** Without it, `fetch` of the bundle's own model JSON is blocked by `connect-src 'none'`. Default: declared. Alternative: ship models as JS modules and drop `connect`.
2. **Two string rewrites in the vendored Jolt file**, pinned by sha256. Default: done and documented.
3. **The "commented example" of reserved capabilities** uses `_comment` / `_reserved_capabilities_example` keys. `parse_manifest` and `parse_connect` read only the keys they know (verified in `crates/sr-activities/src/arcade.rs` and `sandbox.rs`).
4. **Players collide through each character's inner kinematic body**, not `CharacterVsCharacterCollisionSimple`.
5. **Snapshots go through `sdk.state`** (`host:snap`) at 20 Hz, about 1 KiB each. Welcome and full messages go through `input.reply`.
6. **`max_participants: 8`**, one per spawn point.
7. **The host seeds the world from the instance id.** A peer's own seed doesn't matter, because the first snapshot overwrites every body.
8. **Member names come from `getInstanceConnectedParticipants`** (members only). Guests use the relay's `callsign`.

**Land.io**
9. **Bot names:** a person can still name themselves "Lumen bot". Should such names be refused?
10. **Mode minimums (`minHeads`):** rounds 2; Last Land, Shrink and KotH 3; Teams, Infection and Draft Night 4; Classic 0. Backfill is on in the activity and off in the rules defaults.
11. **The keeper pick happens at the start of the next round**, not on the results screen, because inputs freeze between rounds.
12. **A run is 3 rounds** of the mode's 5 minutes. The last round's winner is the run champion.
13. **Set bonuses:** 3 or 5 cards. Runner: 20% / 33% faster recharge. Trickster: a 3 s / 5 s ward. Builder: +8% / +15% score. Tuned against bots only.
14. **Handoff snapshots stay off** until the platform can move the host. A 100×100 snapshot is under 40 KB, about 4–8 KB/s per member at one every 5 s.
15. **Guests set no Rich Presence.**
16. **A host restart, or a change of mode, map or size, starts a new Draft Night run.**
