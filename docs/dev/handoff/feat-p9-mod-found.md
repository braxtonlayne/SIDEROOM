## Gap to know about
There is no client-readable feature-flag endpoint (the only flag API is `/admin/features`). The web store therefore seeds `moderation.reports` from the build-time env `VITE_FEATURE_MODERATION_REPORTS=true` (default off) and exposes `setReportsEnabled()` for a future feed. The server-side flag exists and defaults off. Open question 11 in the spec asks whether to add the endpoint.
