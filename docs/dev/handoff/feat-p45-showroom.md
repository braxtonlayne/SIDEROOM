# Handoff: wave 45-B, Showroom / populated preview (UX-SHOW-001)

Branch `feat/p45-showroom` (base `integration/phase44`). Decisions D-435 to D-437, threat-model row T46. No migration (2170 to 2179 unused).

## Done

Audit first: nothing for a populated preview existed (no fixture overlay, no `showroom` flag). The feature-switch mechanism is the platform feature registry (`crates/sr-features/src/wave_modules.rs`, read by the web through `GET /sr/features/flags` into `useClientFlags`, as the five Study switches of wave 41 do). The only Rust change is one switch.

- **Switch `platform.showroom`** (`wave_modules.rs`, `SHOWROOM_ID`): platform scope, client visible, OFF by default, section Study, phase 45. It gates only the preview; no route, no gate rule. Name and description contain none of the words the immutable suite refuses. Registered in `feature_registry.rs` (expected row) and the web catalog fixture `admin/features/__fixtures__/registry.json` (regenerated by `SR_UPDATE_FEATURE_CATALOG=1`).
- **Toggle**: `showroom/PreviewToggle.tsx`, rendered by `RoomsNav` (so the Lounge section bar, The Study bar, Cinema and Library bars) and on the Arcade page (which has no rooms bar). Hidden unless the switch is on.
- **State**: `showroom/state.ts`, a separate zustand store (`on`, `hint`). Active = switch on AND device choice on; follows the switch live. Choice kept in `localStorage` key `sr.showroom.v1` inside try/catch (D-437).
- **Banner**: `showroom/ShowroomBanner.tsx`, mounted in `app/main.tsx` inside `CatalogGate`: "Preview" title, "made-up sample data" text, a live-region hint, and a "Turn preview off" button.
- **Overlay layer** (D-436): the preview replaces the screen, never the data. The real stores and query cache are not read or written for sample objects.
  - Rail: `ShowroomRailSlot` (eager, tiny) lazy-loads `PreviewRailItems` and adds ten sample servers under the real ones (voice icon, unread pill, mention badges, muted one). They are buttons, not links; click shows the hint.
  - The Study: `StudyPage` became a wrapper that shows lazy `PreviewStudy` while active, else the unchanged page (`RealStudyPage`). Sample My Files, 3 friend shelves, 3 server shelves; source filter (Everything / My Files / Friends / Servers), kind filter, per-shelf selection, and a local metadata view (size, added, tags, note, "kept on this device only"). Open / Pin / Edit note only show the hint.
  - The Arcade: same wrapper pattern with lazy `PreviewArcade`: a "PLAYABLE NOW" section (3 live builds) apart from a "PREVIEW / IN DEVELOPMENT" section (4 showcase cards). Play / Notify me only show the hint. The real page is not mounted, so `api.front()` is never called.
- **Fixtures**: `showroom/fixtures.ts`, invented names only (`demo_` handles, "(sample)" titles). Imported only by the lazy preview chunks (D-385); a test scans the imports.
- **i18n**: `i18n/messages/en/p45-showroom-1.ts` (keys `showroom.*`).
- **Docs**: inventory section "Wave 45" header (45-A had not written it yet; added identically) with the UX-SHOW-001 row, D-435 to D-437, T46.
