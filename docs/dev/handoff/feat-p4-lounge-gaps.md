## Decisions and things to know
1. Picture size and BlurHash are declared by the uploading client in the upload-slot request and stored in the existing `attachments.width/height/blurhash` columns. The server does not decode pictures (it never sees them except to strip metadata), so these are layout hints, validated for shape only (1 to 16384 px, both or neither; base-83, 6 to 128 chars). Documented in doc 05.
2. Bookmarks and reminders live in the user settings blob (`bookmarks`, `reminders`, keyed by message id; documented in doc 04) and are written as direct merge patches. They do not go through `userSettingsSync` (so they cannot clobber its pending rail changes); a settings blob that loads late does not undo an entry still being saved.
3. Age gate: `POST /sr/age-gate {over_18}` both for yes and no, as doc 06 describes for the Library. The API cannot read the stored answer back, so it is also remembered per account in localStorage. The server does not stop restricted channels itself (Discord's gate is also a UX gate); channel history is simply not requested until the viewer answers. A "no" blocks the channel and the guild landing never redirects into a restricted channel. Merge note for the Library agent: `lounge/AgeGate.tsx` has no Lounge dependencies; `postAgeGate` and `AgeConfirmPrompt` are the parts a shared `useAgeGate()` hook can wrap, `useAgeGate(restricted)` is the Lounge-specific state.
4. Syntax highlighting keeps Shiki but uses `shiki/core` with the JavaScript regex engine and about 30 lazy grammars (alias table in `highlight.tsx`) instead of the full bundle: build output went from 12 MB to 4 MB and the Oniguruma WASM is gone. Anything outside the list stays plain text. Licences: Shiki and its grammars/themes are MIT/permissive, already in the lockfile.
5. Compact mode puts name and time on every line and disables grouping, driven by the saved `messageDisplay` pref.
6. Threads live in their own store (`lounge/threads/threadStore.ts`), not in the channel list, so they never appear in the sidebar. The thread pane is the existing `/channels/:g/:c/threads/:t` route, which was defined but rendered nothing.
7. The Lounge test helpers `__tests__/gapsHelpers.tsx` raise the RTL query timeout to 6 s and the test timeout to 30 s because these flows click through several menus.
