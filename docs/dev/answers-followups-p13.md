# Implementation follow-ups from the Phase 12 and 13 remaining answers

Work implied by the adopted answers in [open-question-answers.md](../open-question-answers.md) ("Phase 12 and 13 remaining questions (answered 2026-10-15)") and decisions D-225 to D-233 in [01-decisions-log.md](../01-decisions-log.md). Same conventions as [answers-followups-p12.md](answers-followups-p12.md): each item says what to change, where, and a size (XS = an hour or two, S = under half a day, M = one to two days, L = more). Pick items by number; put the question or decision id in the branch name or PR title (for example `feat/D-225-epub-reader`). Tick an item here when it merges. Migrations for this round are `0870` to `0879`, assigned per item below; never renumber a merged file. Items that only touch docs or inventory are grouped at the end. Where an item builds on a Phase 13 branch that has not merged yet, the branch is named; land on top of it or after it.

Nothing in this round is blocked on the owner.
